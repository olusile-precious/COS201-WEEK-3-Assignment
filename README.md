INTRODUCTION

This repository contains three Java programs developed as part of the COS 201 Computer Programming I Week 3 assignment.

PROGRAMS

1. SimpleCalculator.java

This program performs basic mathematical operations:

Addition

Subtraction

Multiplication

Division

2. AverageCalculator.java

This program accepts numbers from the user, calculates their sum and displays the average.

3. ItemCost.java

This program accepts an item name, quantity and price per item, then calculates and displays the total cost.

PROGRAMMING LANGUAGE

Java

HOW TO RUN THE PROGRAMS

Install Java Development Kit (JDK).

Open the program using a Java IDE or text editor.

Compile the program using javac filename.java.

Run it using java ClassName.

Follow the instructions displayed on the screen.
